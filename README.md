# Projeto de Prática em Automação de Testes

Este repositório foi criado exclusivamente para a prática de conceitos de automação de testes de ponta a ponta (E2E), utilizando o site [SauceDemo](https://saucedemo.com) como aplicação de testes.

O objetivo é exercitar a escrita de scripts, a manipulação de elementos web e a estruturação de cenários automatizados.

## 🛠️ Tecnologias Utilizadas

*   [Playwright](https://playwright.dev) - Framework para automação de navegadores.
*   [TypeScript](https://typescript.org) - Linguagem de programação para maior segurança no código.
*   [Node.js](https://nodejs.org) - Ambiente de execução do projeto.
